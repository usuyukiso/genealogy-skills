# Genealogy Biography — навык для семейной истории по документам

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

**Навык (Agent Skill) для Claude Code, который пишет биографию предка по архивным документам и публикует её страницей сайта по истории семьи.** Обычно на входе — хронологическая таблица (одна строка — одно событие жизни: рождения, браки, смерти, переписи, исповедные росписи, восприемничество, переезды, смена сословия), но подойдут и заметки, ссылки или сканы. На выходе — понятный рассказ о жизни человека, где у каждого факта есть источник, а каждая цитата дословна, и по отдельной странице на каждый документ.

Навык сделан для русскоязычного сайта на [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) о семьях из Российской империи и СССР. Инструкции в нём написаны по-английски, а текст для сайта он пишет по-русски (или на языке, который вы попросите); цитаты из документов сохраняют дореформенную орфографию.

---

## Что он делает

- **Страница биографии.** Рассказ о жизни по периодам, список семьи, хронология, замечания о расхождениях между документами и отдельный блок исследовательских заметок для предположений.
- **Страницы источников.** По странице на каждый документ: полный архивный шифр (архив, фонд, опись, дело, лист), где лежит скан, названия граф бланка, дословный текст записи и пояснения к неуверенным прочтениям. Страница одна на документ, даже если он нужен нескольким биографиям.
- **Дословные цитаты.** Записи цитируются точно, с исходной орфографией. На странице источника сказано, откуда взят текст: прочтение скана, расшифровка составителя, расшифровка других исследователей (со ссылкой) или распознавание Яндекс Архива. Неуверенное слово помечено `[?]`, нечитаемое место — `[…]` или `[неразборчиво]`.
- **Помощник для Яндекс Архива.** `scripts/yandex_archive.py` берёт распознанный текст и архивный шифр скана и ищет по архиву. Распознанный текст — черновик: его сверяют со сканом, исправления показывают.
- **Постоянные идентификаторы.** У каждой страницы постоянный ID (`P1000` — человек, `A1000` — архивная запись, `B` — книга, `F` — фото, `W` — веб-страница, `PLC` — место…). `scripts/next_id.py` выдаёт следующий свободный ID и проверяет, нет ли у документа уже страницы, — так ничего не дублируется.
- **Указатель имён.** Каждый, кто назван в записи о человеке, — родные, восприемники, свидетели, соседи, священники — получает строку в общем указателе; женщины — под каждой известной фамилией.
- **Места.** Люди связываются со страницами населённых пунктов; дореволюционное административное деление приводится по документам с годом источника.
- **Строгая сборка.** В конце сайт собирается в строгом режиме: битая ссылка или неизвестный ID останавливают работу, пока их не исправят.

## Каким правилам он следует

- **Ничего не выдумывать.** Никаких имён, дат, родственников, шифров и цитат, которых нет во входных данных. Если документы молчат, так и написано.
- **Каждый факт со ссылкой,** и ссылка ведёт к нужной записи, а не к обзорной странице.
- **Выводы помечены.** Гипотеза идёт в исследовательские заметки и начинается словами «Предположение (не подтверждено документами)», с доводами за и против и с тем, что может её подтвердить.
- **Родство — по звеньям.** У каждой связи «родитель — ребёнок» и «муж — жена» свои источники; дальний предок доказан, только если доказано каждое звено. Копии одной записи — один источник. Отчество называет имя отца, но не показывает, какой это человек; общая фамилия, деревня или двор — не доказательство родства.
- **Тёзки раздельно.** Двух людей с одинаковыми именем и отчеством из одной деревни не объединяют, пока документы их не различат.
- **Расхождения не скрываются.** Обе версии приводятся рядом — с тем, кто и когда сообщил сведения.
- **Отсутствие записи — не доказательство,** что события не было; на странице сказано, какие книги и годы просмотрены.
- **Каждый просмотр архива записывается,** и с находкой, и без, во внутренний реестр (`internal/checks/reviewed_documents.md`), чтобы через годы не искать то же самое заново.
- **Рабочая таблица на сайте не упоминается:** читатель видит только настоящие источники.

## Что нужно

- [Claude Code](https://claude.com/claude-code) или другая среда с поддержкой Agent Skills.
- Python 3 (только стандартная библиотека).
- Сайт с ожидаемой структурой: `family_tree_github/` с папками `docs/people/`, `docs/sources/{archives,books,photos,websites}/`, `docs/places/`, указателями и `mkdocs.yml`, а также хук ссылок по ID (`hooks/id_links.py`). Пути прописаны в навыке; для другого сайта поправьте таблицу «Where the output goes» в `SKILL.md` и путь `DOCS` в `scripts/next_id.py` (или задайте переменную окружения `DOCS`).
- По желанию — навык **chronology-table**: он читает хронологические таблицы `.ods`, `.xlsx`, `.csv` и подключается сам, если на входе таблица.

## Установка

Навык входит в набор [genealogy-skills](https://github.com/usuyukiso/genealogy-skills). Склонируйте набор и скопируйте эту папку вместе с **chronology-table**, которым навык читает таблицы (имя папки — это имя навыка):

```bash
git clone https://github.com/usuyukiso/genealogy-skills ~/genealogy-skills
cp -r ~/genealogy-skills/genealogy-biography ~/genealogy-skills/chronology-table <проект>/.claude/skills/
```

или в личные навыки (`~/.claude/skills/`), чтобы пользоваться ими во всех проектах. Об остальных навыках и о том, как они работают вместе, — в README набора.

## Как пользоваться

Навык запустится сам, если ваша просьба ему подходит, — просто опишите задачу в Claude Code (или запустите напрямую: `/genealogy-biography`), например:

- *«Напиши биографию Евдокии Лапиной по таблице `sources/people_all.xlsx`»*
- *«Обнови страницу Григория Писарева: добавь донесение о потерях 1943 года с цитатой»*
- *«Напиши биографию по этим трём сканам метрических книг в Яндекс Архиве»*

Помощники можно запускать и вручную из корня проекта:

```bash
python3 .claude/skills/genealogy-biography/scripts/next_id.py next A A P          # следующие свободные ID
python3 .claude/skills/genealogy-biography/scripts/next_id.py find "23И, оп. 2, д. 24"  # уже есть на сайте?
python3 .claude/skills/genealogy-biography/scripts/yandex_archive.py page "<ссылка на скан>"
python3 .claude/skills/genealogy-biography/scripts/yandex_archive.py search "Лапина Корсаковск"
```

В конце агент сообщает, какие страницы написал и какие использовал повторно, сколько людей добавлено в указатель, какие записи процитированы по сканам, у каких нет текста, и какие расхождения стоит проверить.

## Файлы

| Путь | Назначение |
|---|---|
| `SKILL.md` | Инструкции, которым следует агент |
| `references/terms.md` | Расшифровка сокращений архивов (ГИАСО, РГИА ДВ…) и терминов записей; пополняется по мере работы |
| `scripts/next_id.py` | Следующий свободный ID, поиск дублей, список всех ID |
| `scripts/yandex_archive.py` | Распознанный текст и шифр скана Яндекс Архива; поиск по архиву |

## Ограничения

- В машинном распознавании (Яндекс Архив) бывают ошибки в именах, числах и датах; навык помечает такой текст и просит сверить его со сканом.
- Навык пишет только то, что подтверждают входные данные. Сам он ищет только в Яндекс Архиве; поиск новых записей — отдельная исследовательская работа.
- Живые люди: сайт открытый, поэтому публикуйте только то, на что согласна семья.
