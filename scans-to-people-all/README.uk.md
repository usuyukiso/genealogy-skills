# scans-to-people-all

Мови: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входить до набору [genealogy-skills](../README.uk.md).

Переписує сповідний розпис (або метричну книгу, або подібний церковний документ) зі сканів до таблиці `sources/people_all.xlsx`, аркуш `people_all2` — рядок на людину, **точно як написано в документі** (Татиана, Иоанн, по батькові «Петров»). Потім зупиняється й чекає, доки ви перевірите рядки.

## Як запустити

Навичка запуститься сама, якщо ваше прохання їй підходить, — просто опишіть завдання в Claude Code, наприклад:

- «Внеси скани 078–081 до people_all»
- «Оцифруй наступні чотири аркуші сповідного розпису»
- «Перепиши ці скани розпису в таблицю»

Або запустіть напряму: `/scans-to-people-all <скани>`.

## Що вийде

- Нові рядки в `people_all2`: прізвище, ім'я, по батькові, вік, рік народження, номер двору, порядкові номери за статтю, спорідненість («жена», «дети их»), аркуш і назва файлу скану.
- Погано читабельні слова **залито жовтим** із позначкою «читается неуверенно (А / Б)» — ви звіряєте їх зі сканом і знімаєте заливку.
- Прізвище чи по батькові, яких немає в самому документі, — курсивом.
- Короткий звіт: скільки людей на кожному аркуші, скільки непевних прочитань.

**Наступний крок:** коли перевірите рядки, попросіть форму Archidocs — це навичка [archidocs-form](../archidocs-form/README.uk.md).

## Що потрібно

- Python 3 і `openpyxl` (`pip3 install openpyxl`).
- `people_all.xlsx` має бути закритий у LibreOffice/Excel, доки навичка в нього пише.

Інструкції, яких дотримується агент, — у [SKILL.md](SKILL.md).
