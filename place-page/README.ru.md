# place-page

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входит в набор [genealogy-skills](../README.ru.md).

Создаёт или приводит в порядок страницу деревни (населённого пункта) на сайте семейной истории так, чтобы она читалась по времени: сначала церковный приход по периодам, затем административное деление до 1917 года по периодам (губа XVIII века, потом уезд и волость), таблица всех упоминаний деревни в документах по годам — как она названа и в какой губе — и выводы составителя (например, прежнее название деревни) под отдельными заголовками, на которые могут ссылаться страницы источников.

## Как запустить

Навык запустится сам, если просьба ему подходит, например:

- «На странице Горелика сделай список всех упоминаний по годам»
- «Сделай страницу деревни Боровово»
- «Перенеси церковный приход в начало страницы Маковиц»

Или запустите напрямую: `/place-page <деревня>`.

## Что получится

- Страница `docs/places/PLC…-<slug>.md` в постоянном порядке: первый абзац, церковный приход, деление до 1917 г. по периодам, упоминания по годам, выводы, после 1917 г., люди, источники.
- Список мест и меню синхронизированы; сайт собран в строгом режиме.

## Что нужно

- Сайт MkDocs `family_tree_github/` и скрипты [genealogy-biography](../genealogy-biography/README.ru.md) (`next_id.py`).

Инструкции, которым следует агент, — в [SKILL.md](SKILL.md).
