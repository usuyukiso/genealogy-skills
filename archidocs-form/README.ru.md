# archidocs-form

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входит в набор [genealogy-skills](../README.ru.md).

Делает таблицу для загрузки людей в Archidocs из строк `people_all.xlsx`, которые **вы уже проверили**. В форме имена современные (Татиана → Татьяна, Иоанн → Иван, «Петров» → Петрович); фамилии остаются как в документе.

## Как запустить

Навык запустится сам, если ваша просьба ему подходит, — просто опишите задачу в Claude Code, например:

- «Сделай форму Archidocs для части 4»
- «Я проверил строки, собери форму для загрузки»
- «Пересобери формы Archidocs после моих правок в people_all»

Или запустите напрямую: `/archidocs-form <часть или сканы>`.

**Первый шаг** (перед этим): перенос сканов в `people_all` — навык [scans-to-people-all](../scans-to-people-all/README.ru.md).

## Что получится

- Папка `archidocs_ready_to_send_part.N` с 4 сканами и формой `form_output_…_part.N.xlsx`, строка на человека: фамилия, имя, отчество, год рождения, тип и год документа, место, название документа, архивный шифр, имя файла, комментарий.
- Список имён, изменённых при переводе в современную форму, — чтобы вы могли их проверить.
- Пересобранные прежние части, если вы позже поправили их строки в `people_all`.

Загружаете форму в Archidocs вы сами.

## Что нужно

- Python 3 и `openpyxl` (`pip3 install openpyxl`).

Инструкции, которым следует агент, — в [SKILL.md](SKILL.md).
