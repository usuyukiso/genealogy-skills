# archidocs-form

Мови: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входить до набору [genealogy-skills](../README.uk.md).

Робить таблицю для завантаження людей в Archidocs із рядків `people_all.xlsx`, які **ви вже перевірили**. У формі імена сучасні (Татиана → Татьяна, Иоанн → Иван, «Петров» → Петрович); прізвища залишаються як у документі.

## Як запустити

Навичка запуститься сама, якщо ваше прохання їй підходить, — просто опишіть завдання в Claude Code, наприклад:

- «Зроби форму Archidocs для частини 4»
- «Я перевірив рядки, збери форму для завантаження»
- «Перезбери форми Archidocs після моїх виправлень у people_all»

Або запустіть напряму: `/archidocs-form <частина чи скани>`.

**Перший крок** (перед цим): перенесення сканів до `people_all` — навичка [scans-to-people-all](../scans-to-people-all/README.uk.md).

## Що вийде

- Папка `archidocs_ready_to_send_part.N` із 4 сканами й формою `form_output_…_part.N.xlsx`, рядок на людину: прізвище, ім'я, по батькові, рік народження, тип і рік документа, місце, назва документа, архівний шифр, назва файлу, коментар.
- Список імен, змінених під час переведення в сучасну форму, — щоб ви могли їх перевірити.
- Перезібрані попередні частини, якщо ви пізніше виправили їхні рядки в `people_all`.

Завантажуєте форму в Archidocs ви самі.

## Що потрібно

- Python 3 і `openpyxl` (`pip3 install openpyxl`).

Інструкції, яких дотримується агент, — у [SKILL.md](SKILL.md).
