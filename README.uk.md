# Навички для генеалогії

Мови: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

**Набір навичок (Agent Skills) для Claude Code для дослідження родинної історії за документами Російської імперії та СРСР:** читання архівних сканів і метричних книг, перенесення їх до таблиці та до форми для завантаження в Archidocs, біографії предків із посиланнями на джерела для сайту з історії родини.

Кожна навичка — папка з `SKILL.md` (інструкції для агента), допоміжними скриптами й власним README. Запускати їх вручну не потрібно: ви описуєте завдання звичайними словами, і Claude сам запускає відповідну навичку. Навички передають роботу одна одній, тож корисно знати ланцюжок нижче.

---

## Навички

| Навичка | Що робить | Як попросити, наприклад |
|---|---|---|
| [archive-scan-search](archive-scan-search/README.uk.md) | Шукає у великій папці архівних сканів (тисячі кадрів, багато справ): розпізнає всі кадри, прив'язує кадри до справ за картками мікрофільму, шукає за частинами слів, перевіряє кожну знахідку за сканом, складає покажчик поселень | «Поищи деревню Глазки в делах Крестьянского банка по Ржевскому уезду» |
| [metric-book-index](metric-book-index/README.uk.md) | Читає метричну книгу кадр за кадром і складає внутрішній покажчик усіх народжень, шлюбів і смертей, із ★ у шуканих людей; можна продовжити з того місця, де зупинилися | «Дочитай метрики Дрогачева за 1892 год» |
| [scans-to-people-all](scans-to-people-all/README.uk.md) | Переписує сповідний розпис або книгу до `people_all.xlsx` (аркуш `people_all2`) — рядок на людину, у написанні документа; сумнівне — жовтим; потім зупиняється й чекає вашої перевірки | «Внеси сканы 078–081 в people_all» |
| [archidocs-form](archidocs-form/README.uk.md) | Робить форму для завантаження в Archidocs із рядків, які ви перевірили, із сучасними іменами та по батькові; звіряє попередні частини з вашими пізнішими виправленнями | «Сделай форму Archidocs для части 4» |
| [chronology-table](chronology-table/README.uk.md) | Читає хронологічну таблицю (рядок — подія життя, `.ods/.xlsx/.csv`) і дає чистий список фактів із джерелами, коментарями й посиланнями | її викликає genealogy-biography; або «Проверь таблицу по Лапиной» |
| [genealogy-biography](genealogy-biography/README.uk.md) | Пише сторінку людини на сайті: розповідь про життя з дослівними цитатами, сторінку на кожен документ, покажчик імен, зв'язки з місцями; збирає сайт і перевіряє посилання | «Напиши биографию Якова Писарева» |

## Як вони пов'язані

```
 знайти записи                   оцифрувати                       опублікувати
 ─────────────                   ──────────                       ────────────
 archive-scan-search ─┐
   (великі папки      │          scans-to-people-all
    сканів)           │            (people_all2)                  chronology-table
 metric-book-index  ──┤               │                                │
   (одна книга        │          ви перевіряєте рядки                  ▼
    парафії)          │               ▼                          genealogy-biography
                      │          archidocs-form                  (сторінки людей
                      │          (форма для завантаження)         і джерел)
                      │                                                ▲
                      └──────── знахідка про члена родини ─────────────┘
                                 (лише на ваше прохання)
```

- **Пошукові навички сайт не змінюють.** archive-scan-search і metric-book-index пишуть лише внутрішні файли: покажчики, нотатки, реєстр переглядів. Знахідка стає сторінкою сайту лише на ваше прохання — її пише genealogy-biography.
- **Між двома кроками оцифрування таблицю перевіряєте ви.** scans-to-people-all зупиняється після запису рядків; archidocs-form бере лише перевірені рядки.
- **Усе переглянуте записується,** зокрема й пошуки без знахідок, до `family_tree_github/internal/checks/reviewed_documents.md`. Кожна навичка дивиться цей реєстр перед пошуком і доповнює його після, щоб одну справу не шукали двічі.
- **Відкриті питання та розбіжності** між документами йдуть до `research_open_questions.md`.

## Спільні правила всіх навичок

- Нічого не вигадувати: імена, дати, спорідненість, шифри й цитати — лише з документів. Якщо документи мовчать, так і написано.
- Цитати дослівно, у первісному правописі; непевне слово — `[?]`, нечитабельне місце — `[…]`. Машинно розпізнаний текст служить лише для пошуку місця в сканах і без читання скану не цитується.
- Спорідненість доводиться за ланками; по батькові, спільне прізвище чи село — не доказ; тезки залишаються різними людьми, доки документи їх не розрізнять.
- Відсутність запису — не доказ, що події не було.
- Висновки позначено як припущення — із тим, що може їх підтвердити чи спростувати.

## Що потрібно

- [Claude Code](https://claude.com/claude-code) (або інше середовище з Agent Skills).
- Python 3. Навичкам із таблицями (scans-to-people-all, archidocs-form) потрібен `openpyxl`; іншим — лише стандартна бібліотека.
- macOS для archive-scan-search і для вирізання фрагментів сканів (Swift і вбудоване розпізнавання тексту Vision).
- Структура проєкту, під яку написано навички (шляхи прописано у файлах `SKILL.md`; для іншого проєкту їх треба виправити):

```
<проєкт>/
  .claude/skills/          ← ці навички
  family_tree_github/      ← сайт на MkDocs Material: docs/people, docs/sources, docs/places,
                             internal/checks (реєстр переглядів, покажчики поселень),
                             internal/metrics (покажчики книг)
  sources/                 ← скани й таблиці (people_all.xlsx, хронології)
  research_open_questions.md
```

## Встановлення

Знадобляться [Git](https://git-scm.com/downloads), Python 3 і [Claude Code](https://claude.com/claude-code) (або Codex). Для двох навичок із таблицями один раз встановіть `openpyxl`:

```bash
pip3 install openpyxl
```

1. **Завантажте репозиторій:**

   ```bash
   git clone https://github.com/usuyukiso/genealogy-skills
   ```

2. **Скопіюйте потрібні навички до папки `skills`.** Кожна навичка — це папка (`genealogy-biography`, `metric-book-index`, …); копіюйте папку цілком.
   - Claude Code: `.claude/skills/` у папці вашого проєкту (якщо її немає — створіть).
   - Codex: `~/.codex/skills/`.

   Копіюйте самі папки навичок, а не всю папку `genealogy-skills`. Навичці genealogy-biography потрібна chronology-table — скопіюйте обидві.

3. **Перезапустіть Claude Code.** Наберіть `/` — навички з'являться у списку. Як запустити кожну навичку і що в неї просити — у її власному README (посилання в таблиці вище).

Щоб оновити, виконайте `git pull` у завантаженій папці й скопіюйте навички знову.

## Як користуватися

1. Відкрийте термінал **у папці проєкту** (там, де `family_tree_github/` і `sources/`) і запустіть Claude Code: `claude`.
2. Опишіть завдання своїми словами, будь-якою мовою. Навичка запуститься сама, якщо ваше прохання їй підходить. Наприклад:
   - «Треба прочитати й оцифрувати метрики» → metric-book-index
   - «Поищи деревню Глазки в делах Крестьянского банка по Ржевскому уезду» → archive-scan-search
   - «Внеси сканы 078–081 в people_all» → scans-to-people-all; ви перевіряєте рядки; потім «Сделай форму Archidocs для части 4» → archidocs-form
   - «Напиши биографию Якова Писарева по таблице» → genealogy-biography (разом із chronology-table)
3. Щоб запустити певну навичку самому, почніть повідомлення з `/` і її назви: `/metric-book-index дочитай Дрогачево`.
4. Довгі завдання (розпізнавання тисяч кадрів, ціла метрична книга) йдуть кроками; навички зберігають поступ у своїх файлах, тож можна зупинитися, а потім сказати «продовжуй» — робота піде з того самого місця.
5. Наприкінці прочитайте звіт агента: що знайдено, що не знайдено, що треба перевірити вам. На сайт нічого не потрапляє, доки ви не попросите.
