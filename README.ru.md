# Навыки для генеалогии

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

**Набор навыков (Agent Skills) для Claude Code для исследования семейной истории по документам Российской империи и СССР:** чтение архивных сканов и метрических книг, перенос их в таблицу и в форму для загрузки в Archidocs, биографии предков со ссылками на источники для сайта по истории семьи.

Каждый навык — папка с `SKILL.md` (инструкции для агента), вспомогательными скриптами и своим README. Запускать их вручную не нужно: вы описываете задачу обычными словами, и Claude сам запускает подходящий навык. Навыки передают работу друг другу, поэтому полезно знать цепочку ниже.

---

## Навыки

| Навык | Что делает | Как попросить, например |
|---|---|---|
| [archive-scan-search](archive-scan-search/README.ru.md) | Ищет в большой папке архивных сканов (тысячи кадров, много дел): распознаёт все кадры, привязывает кадры к делам по карточкам микрофильма, ищет по кускам слов, проверяет каждую находку по скану, составляет указатель селений | «Поищи деревню Глазки в делах Крестьянского банка по Ржевскому уезду» |
| [metric-book-index](metric-book-index/README.ru.md) | Читает метрическую книгу кадр за кадром и составляет внутренний указатель всех рождений, браков и смертей, с ★ у искомых людей; можно продолжить с того места, где остановились | «Дочитай метрики Дрогачева за 1892 год» |
| [scans-to-people-all](scans-to-people-all/README.ru.md) | Переписывает исповедную ведомость или книгу в `people_all.xlsx` (лист `people_all`) — строка на человека, в написании документа; сомнительное — жёлтым; потом останавливается и ждёт вашей проверки | «Внеси сканы 078–081 в people_all» |
| [archidocs-form](archidocs-form/README.ru.md) | Делает форму для загрузки в Archidocs из строк, которые вы проверили, с современными именами и отчествами; сверяет прежние части с вашими поздними правками | «Сделай форму Archidocs для части 4» |
| [chronology-table](chronology-table/README.ru.md) | Читает хронологическую таблицу (строка — событие жизни, `.ods/.xlsx/.csv`) и даёт чистый список фактов с источниками, комментариями и ссылками | его вызывает genealogy-biography; или «Проверь таблицу по Лапиной» |
| [genealogy-biography](genealogy-biography/README.ru.md) | Пишет страницу человека на сайте: рассказ о жизни с дословными цитатами, страницу на каждый документ, указатель имён, связи с местами; собирает сайт и проверяет ссылки | «Напиши биографию Якова Писарева» |

## Как они связаны

```
 найти записи                    оцифровать                       опубликовать
 ────────────                    ──────────                       ────────────
 archive-scan-search ─┐
   (большие папки     │          scans-to-people-all
    сканов)           │            (people_all)                   chronology-table
 metric-book-index  ──┤               │                                │
   (одна книга        │          вы проверяете строки                  ▼
    прихода)          │               ▼                          genealogy-biography
                      │          archidocs-form                  (страницы людей
                      │          (форма для загрузки)             и источников)
                      │                                                ▲
                      └──────── находка о члене семьи ─────────────────┘
                                 (только по вашей просьбе)
```

- **Поисковые навыки сайт не меняют.** archive-scan-search и metric-book-index пишут только внутренние файлы: указатели, заметки, реестр просмотров. Находка становится страницей сайта только по вашей просьбе — её пишет genealogy-biography.
- **Между двумя шагами оцифровки таблицу проверяете вы.** scans-to-people-all останавливается после записи строк; archidocs-form берёт только проверенные строки.
- **Всё просмотренное записывается,** в том числе поиски без находок, в `family_tree_github/internal/checks/reviewed_documents.md`. Каждый навык смотрит этот реестр перед поиском и дописывает его после, чтобы одно дело не искали дважды.
- **Открытые вопросы и расхождения** между документами идут в `research_open_questions.md`.

## Общие правила всех навыков

- Ничего не выдумывать: имена, даты, родство, шифры и цитаты — только из документов. Если документы молчат, так и написано.
- Цитаты дословно, в исходной орфографии; неуверенное слово — `[?]`, нечитаемое место — `[…]`. Машинно распознанный текст служит только для поиска места в сканах и без чтения скана не цитируется.
- Родство доказывается по звеньям; отчество, общая фамилия или деревня — не доказательство; тёзки остаются разными людьми, пока документы их не различат.
- Отсутствие записи — не доказательство, что события не было.
- Выводы помечены как предположения — с тем, что может их подтвердить или опровергнуть.

## Что нужно

- [Claude Code](https://claude.com/claude-code) (или другая среда с Agent Skills).
- Python 3. Навыкам с таблицами (scans-to-people-all, archidocs-form) нужен `openpyxl`; остальным — только стандартная библиотека.
- macOS для archive-scan-search и для вырезания фрагментов сканов (Swift и встроенное распознавание текста Vision).
- Структура проекта, под которую написаны навыки (пути прописаны в файлах `SKILL.md`; для другого проекта их нужно поправить):

```
<проект>/
  .claude/skills/          ← эти навыки
  family_tree_github/      ← сайт на MkDocs Material: docs/people, docs/sources, docs/places,
                             internal/checks (реестр просмотров, указатели селений),
                             internal/metrics (указатели книг)
  sources/                 ← сканы и таблицы (people_all.xlsx, хронологии)
  research_open_questions.md
```

## Установка

Понадобятся [Git](https://git-scm.com/downloads), Python 3 и [Claude Code](https://claude.com/claude-code) (или Codex). Для двух навыков с таблицами один раз установите `openpyxl`:

```bash
pip3 install openpyxl
```

1. **Скачайте репозиторий:**

   ```bash
   git clone https://github.com/usuyukiso/genealogy-skills
   ```

2. **Скопируйте нужные навыки в папку `skills`.** Каждый навык — это папка (`genealogy-biography`, `metric-book-index`, …); копируйте папку целиком.
   - Claude Code: `.claude/skills/` в папке вашего проекта (если её нет — создайте).
   - Codex: `~/.codex/skills/`.

   Копируйте сами папки навыков, а не всю папку `genealogy-skills`. Навыку genealogy-biography нужен chronology-table — скопируйте оба.

3. **Перезапустите Claude Code.** Наберите `/` — навыки появятся в списке. Как запустить каждый навык и что у него просить — в его собственном README (ссылки в таблице выше).

Чтобы обновить, выполните `git pull` в скачанной папке и скопируйте навыки заново.

## Как пользоваться

1. Откройте терминал **в папке проекта** (там, где `family_tree_github/` и `sources/`) и запустите Claude Code: `claude`.
2. Опишите задачу своими словами, на любом языке. Навык запустится сам, если ваша просьба ему подходит. Например:
   - «Нужно прочитать и оцифровать метрики» → metric-book-index
   - «Поищи деревню Глазки в делах Крестьянского банка по Ржевскому уезду» → archive-scan-search
   - «Внеси сканы 078–081 в people_all» → scans-to-people-all; вы проверяете строки; потом «Сделай форму Archidocs для части 4» → archidocs-form
   - «Напиши биографию Якова Писарева по таблице» → genealogy-biography (вместе с chronology-table)
3. Чтобы запустить определённый навык самому, начните сообщение с `/` и его имени: `/metric-book-index дочитай Дрогачево`.
4. Длинные задачи (распознавание тысяч кадров, целая метрическая книга) идут по шагам; навыки сохраняют прогресс в своих файлах, поэтому можно остановиться, а потом сказать «продолжи» — работа пойдёт с того же места.
5. В конце прочитайте отчёт агента: что найдено, что не найдено, что нужно проверить вам. На сайт ничего не попадает, пока вы не попросите.
