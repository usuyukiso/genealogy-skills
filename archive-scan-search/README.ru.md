# archive-scan-search

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входит в набор [genealogy-skills](../README.ru.md).

Ищет в большой папке архивных снимков — тысячи кадров из многих дел, например снимки РГИА, ф. 592 (Крестьянский поземельный банк) с velikie.org — деревню, волость или фамилию. Машинно читает все кадры, определяет, к какому делу относится каждый кадр, находит кандидатов, а затем проверяет каждого кандидата по самому скану.

## Как запустить

Навык запустится сам, если ваша просьба ему подходит, — просто опишите задачу в Claude Code, например:

- «Поищи деревню Глазки в делах Крестьянского банка по Ржевскому уезду»
- «Прочитай Гомельский уезд, там наши деревни Глазовка и Рудня-Бартоломеевская»
- «Составь список населённых пунктов, которые упоминаются в этих делах»

Или запустите напрямую: `/archive-scan-search <папка> <что искать>`.

Первый запуск на новой папке распознаёт все кадры, это долго (около получаса на 7000 кадров). Делается один раз; следующие поиски по той же папке занимают минуты.

## Что получится

- Что найдено: дело, год, строка о нём, кадры, которые стоит открыть, — всё проверено по скану.
- Что не найдено и почему оно всё же может там быть (рукописные списки машина читает плохо).
- Указатель населённых пунктов из дел, по волостям, — для будущих поисков.
- Запись в реестре просмотров, в том числе о поисках без находок, чтобы ту же папку не искали заново. Сайт не меняется.

## Что нужно

- macOS (встроенное в систему распознавание текста, Swift), Python 3.
