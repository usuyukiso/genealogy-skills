# archive-scan-search

Мови: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входить до набору [genealogy-skills](../README.uk.md).

Шукає у великій папці архівних знімків — тисячі кадрів із багатьох справ, наприклад знімки РДІА, ф. 592 (Селянський поземельний банк) з velikie.org — село, волость чи прізвище. Машинно читає всі кадри, визначає, до якої справи належить кожен кадр, знаходить кандидатів, а потім перевіряє кожного кандидата за самим сканом.

## Як запустити

Навичка запуститься сама, якщо ваше прохання їй підходить, — просто опишіть завдання в Claude Code, наприклад:

- «Пошукай село Глазки у справах Селянського банку по Ржевському повіту»
- «Прочитай Гомельський повіт, там наші села Глазовка й Рудня-Бартоломеївська»
- «Склади список населених пунктів, які згадуються в цих справах»

Або запустіть напряму: `/archive-scan-search <папка> <що шукати>`.

Перший запуск на новій папці розпізнає всі кадри, це довго (близько пів години на 7000 кадрів). Робиться один раз; наступні пошуки в тій самій папці займають хвилини.

## Що вийде

- Що знайдено: справа, рік, рядок про неї, кадри, які варто відкрити, — усе перевірено за сканом.
- Що не знайдено і чому воно все ж може там бути (рукописні списки машина читає погано).
- Покажчик населених пунктів зі справ, за волостями, — для майбутніх пошуків.
- Запис у реєстрі переглядів, зокрема про пошуки без знахідок, щоб ту саму папку не шукали знову. Сайт не змінюється.

## Що потрібно

- macOS (вбудоване в систему розпізнавання тексту, Swift), Python 3.
