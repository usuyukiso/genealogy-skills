# chronology-table

Языки: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входит в набор [genealogy-skills](../README.ru.md).

Читает хронологическую таблицу об одном человеке — строка на событие жизни (рождения, браки, смерти, переписи, исповедные ведомости, восприемничество, переезды, смена сословия) — и превращает её в чистый список фактов, у каждого — свои источники: архивные шифры, комментарии к ячейкам, ссылки на сканы.

## Как запустить

Навык запустится сам, если ваша просьба ему подходит, — просто опишите задачу в Claude Code, например:

- «Проверь таблицу по Лапиной»
- «Что в таблице сказано о детях Григория?»
- «Напиши биографию по таблице `sources/people_all.xlsx`» — тогда genealogy-biography сам прочитает таблицу этим навыком.

Или запустите напрямую: `/chronology-table <файл>`.

## Что получится

- Таблица, прочитанная по листам, с номерами строк, комментариями к ячейкам и ссылками.
- Список фактов по каждому событию: дата, место, сословие, имя как в документе, упомянутые люди, возраст, источник каждого факта.
- Ошибки самой таблицы (нет источника, даты спорят, опечатки) — сообщаются вам, а не скрываются.

## Что нужно

- Python 3 (только стандартная библиотека). Читает `.ods`, `.xlsx`, `.csv`/`.tsv`.

Инструкции, которым следует агент, — в [SKILL.md](SKILL.md).
