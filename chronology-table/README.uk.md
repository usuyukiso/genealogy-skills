# chronology-table

Мови: [English](README.md) / [Русский](README.ru.md) / [Українська](README.uk.md) / [Deutsch](README.de.md)

Входить до набору [genealogy-skills](../README.uk.md).

Читає хронологічну таблицю про одну людину — рядок на подію життя (народження, шлюби, смерті, переписи, сповідні розписи, хрещення як хрещеного, переїзди, зміна стану) — і перетворює її на чистий список фактів, кожен — зі своїми джерелами: архівні шифри, коментарі до клітинок, посилання на скани.

## Як запустити

Навичка запуститься сама, якщо ваше прохання їй підходить, — просто опишіть завдання в Claude Code, наприклад:

- «Перевір таблицю про Лапіну»
- «Що в таблиці сказано про дітей Григорія?»
- «Напиши біографію за таблицею `sources/people_all.xlsx`» — тоді genealogy-biography сама прочитає таблицю цією навичкою.

Або запустіть напряму: `/chronology-table <файл>`.

## Що вийде

- Таблиця, прочитана за аркушами, з номерами рядків, коментарями до клітинок і посиланнями.
- Список фактів за кожною подією: дата, місце, стан, ім'я як у документі, згадані люди, вік, джерело кожного факту.
- Помилки самої таблиці (немає джерела, дати суперечать, описки) — повідомляються вам, а не приховуються.

## Що потрібно

- Python 3 (лише стандартна бібліотека). Читає `.ods`, `.xlsx`, `.csv`/`.tsv`.

Інструкції, яких дотримується агент, — у [SKILL.md](SKILL.md).
